# SAFE-WM Customer Explanation Prompt v1

## 1. 목적

고객용 설명은 투자 추천이 아니라 자산 안정성 점검 결과를 쉽게 설명하기 위한 문장이어야 한다.

## 2. 작성 지침

- 고령 고객이 이해하기 쉬운 문장 사용
- 위험 원인과 확인 필요 항목 중심
- 투자 상품 권유 금지
- 수익률 또는 가격 방향 단정 금지
- PB 상담을 통해 확인할 수 있다는 문장 사용

## 3. 출력 구성

```text
1. 현재 자산 안정성 요약
2. 주요 위험 요인
3. 생활비/유동성 관점 설명
4. PB와 함께 확인할 항목
```
