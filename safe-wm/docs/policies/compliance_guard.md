# SAFE-WM Compliance Guard Policy v1

## 1. 금지 표현

```text
매수하세요
매도하세요
반드시 상승합니다
반드시 하락합니다
수익을 보장합니다
원금이 보장됩니다
이 상품을 추천합니다
투자해야 합니다
```

## 2. 허용 표현

```text
점검이 필요합니다
상담을 통해 확인할 수 있습니다
위험 요인으로 관찰됩니다
부담이 커질 수 있습니다
가능성을 확인할 필요가 있습니다
```

## 3. FAIL 조건

- 투자권유 표현 포함
- 확정적 수익/손실 예측 포함
- 개인정보 상세 노출
- RAG 근거와 무관한 단정적 설명

## 4. Loop 동작

FAIL 시 Compliance Guard Agent는 RAG Advisor Agent로 재생성 요청을 보낸다.
